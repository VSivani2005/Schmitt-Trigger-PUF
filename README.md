# Schmitt-Trigger PUF: Software-Based Paper Replication

## 1. Project Overview

This project presents a software-based replication and analysis of a Schmitt-trigger-based Physical Unclonable Function (PUF), based on the research paper:

**"Novel PUF Implementation for Microcontrollers and Field Programmable Gate Arrays" — IEEE Access, 2025.**

The project models the behaviour of Schmitt-trigger-based RC oscillators and investigates their use in generating challenge-response pairs (CRPs) for hardware device identification and authentication.

The implementation includes oscillator period modelling, pairwise response generation, virtual device modelling, reliability analysis, entropy evaluation, and an interactive Streamlit dashboard.

The primary objective is to reproduce and analyse the paper's methodology through software experiments before proceeding to physical FPGA validation.

## 2. Research Objectives

The main objectives are:

- Model Schmitt-trigger-based RC oscillator behaviour.
- Generate PUF responses using pairwise oscillator comparisons.
- Simulate multiple virtual devices.
- Generate and analyse 10,000 challenge-response pairs.
- Evaluate response uniqueness and uniformity.
- Analyse response randomness and minimum entropy.
- Investigate response steadiness under repeated measurements.
- Evaluate the effect of averaging on response reliability.
- Study temperature-related reliability variations.
- Analyse error probability.
- Provide an interactive dashboard for viewing experimental results.

## 3. Working Principle

The proposed PUF is based on variations in the oscillation periods of Schmitt-trigger-based RC circuits.

Each oscillator has a slightly different period due to variations in its electrical characteristics.

The period of an oscillator is modelled using the RC charging and discharging behaviour and the Schmitt-trigger threshold voltages.

### 3.1 Oscillator Period Model

The oscillator period is calculated using Equation (5) from the reference paper:

[
P_i = RC \ln\left(
\frac{V\_{iH}(V\_{DD}-V\_{iL})}
{V\_{iL}(V\_{DD}-V\_{iH})}
\right)
]

Where:

- (P_i): Oscillation period of oscillator (i)
- (R): Resistance
- (C): Capacitance
- (V\_{DD}): Supply voltage
- (V\_{iH}): Upper Schmitt-trigger threshold
- (V\_{iL}): Lower Schmitt-trigger threshold

### 3.2 Pairwise Response Generation

The PUF response is generated by comparing the periods of two oscillators.

For oscillators (i) and (j):

[
R\_{ij} =
\begin{cases}
1, & P_i > P_j\\
0, & P_i \leq P_j
\end{cases}
]

The resulting comparison bits form the PUF response.

Different challenge sequences select different oscillator comparisons, producing different challenge-response pairs.

## 12. Scope and Limitations

This repository focuses on software-based modelling and experimental replication.

Important distinctions:

- The reported results are generated using a synthetic software model.
- The five devices represent virtual devices, not five physically measured FPGA boards.
- The temperature and reliability experiments are software simulations.
- The results should not be interpreted as measured physical hardware performance.
- Physical FPGA validation is a separate stage of the project.
